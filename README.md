# MPEI Lite

Unofficial Android companion for Moscow Power Engineering Institute.

Built with Kotlin, Jetpack Compose and Material 3 Expressive.
The app provides Schedule, BARS, Mail, Campus Map and Settings.

Each pull request runs lint and tests. Merging into `main` builds
the signed Android APK and updates the rolling `latest` release.
Versions use Moscow local time: `YYYY.MM.DD.N`.

[Latest APK](https://github.com/rteats/mpei-lite/releases/download/latest/MPEI-Lite.apk)
